Inicio

Página principal de bienvenida al sitio web MotoGP Desktop, diseñada para ofrecer una visión general del proyecto y facilitar el acceso rápido a todas las secciones de información técnica, datos deportivos y entretenimiento disponibles en la plataforma.

Piloto

Sección informativa dedicada a Maverick Viñales que detalla su trayectoria profesional, biografía y datos personales. Incluye una tabla con las estadísticas de la temporada actual, así como una galería multimedia con imágenes responsivas, vídeos y audios relacionados con el piloto.

Circuito

Ofrece información técnica detallada sobre las características del circuito donde se disputa el Gran Premio. En esta página se describen la configuración del trazado, la longitud, las curvas y los sectores, acompañados de recursos multimedia para visualizar el entorno de la carrera.

Carga de información del circuito

Utiliza el API File de HTML5 para permitir la lectura de archivos desde la máquina cliente. Se pueden cargar tres tipos de archivos:

Archivo HTML de información

El archivo infoCircuito.html contiene datos detallados del circuito que se procesan dinámicamente y se integran en la página mediante manipulación del DOM.

Archivo SVG de altimetría

El archivo altimetria.svg representa gráficamente el perfil de altimetría del circuito, mostrando las elevaciones y descensos a lo largo del trazado.

Archivo KML del mapa

El archivo circuito.kml contiene las coordenadas geográficas del trazado. Esta información se utiliza para generar un mapa dinámico interactivo mediante Google Maps API, donde se visualiza el circuito con un marcador en el punto de origen y una polilínea que dibuja el recorrido completo del trazado.

Meteorologia

Muestra la situación climática actual y la predicción del tiempo para la ubicación exacta del circuito. Utiliza tecnologías dinámicas para obtener datos externos y presentar las condiciones específicas previstas para las sesiones de entrenamientos y el día de la carrera.

Clasificaciones

En esta página se utiliza PHP para leer un archivo XML almacenado en el servidor. La aplicación procesa este archivo para mostrar dinámicamente quién ha sido el ganador de la carrera y listar la clasificación actual del mundial de pilotos.

Juegos

Menú central de entretenimiento que agrupa las aplicaciones interactivas del sitio web. Desde aquí se puede acceder al juego de memoria de cartas y a las herramientas de cronometraje, disponibles tanto en versión de cliente (JavaScript) como de servidor (PHP).

Navegación

El sitio web MotoGP Desktop cuenta con un sistema de navegación adaptable que se ajusta automáticamente según el dispositivo utilizado:

Navegación en escritorio

En dispositivos de escritorio y tablets (anchura mayor a 485px), la navegación se muestra como un menú horizontal en la parte superior de la página, acompañado de migas de pan que indican la ubicación actual dentro del sitio.

Navegación en dispositivos móviles

En dispositivos móviles (anchura menor o igual a 485px), la navegación se transforma en un menú desplegable tipo hamburguesa. Un botón con el icono "☰ Menú" permite mostrar u ocultar los enlaces de navegación. Al hacer clic en el botón, el menú se despliega verticalmente con una animación suave. El botón cambia a "✕ Cerrar" cuando el menú está visible. Las migas de pan se ocultan automáticamente en dispositivos móviles para optimizar el espacio en pantalla.

Accesibilidad del menú

El menú móvil implementa estándares de accesibilidad WCAG 2.0 nivel AAA, incluyendo atributos ARIA (aria-label, aria-expanded, aria-controls, aria-hidden) para garantizar la compatibilidad con lectores de pantalla y navegación por teclado.

Tecnologías utilizadas

El proyecto MotoGP Desktop emplea las siguientes tecnologías y estándares web:

HTML5

Utilización de elementos semánticos (section, article, nav, header) y validación completa según los estándares del W3C.

CSS3

Diseño responsive mediante Flexbox, media queries y medidas relativas. Uso de animaciones CSS para mejorar la experiencia de usuario.

JavaScript ES6+

Programación orientada a objetos con clases ECMAScript. Implementación de funcionalidades mediante el API File, manipulación del DOM y DOMParser.

APIs externas

Integración de Google Maps API para mapas interactivos y servicios de geolocalización y cartografía.

Accesibilidad

Cumplimiento de las pautas WCAG 2.0 nivel AAA con uso de atributos ARIA, etiquetas semánticas y navegación por teclado.
